RECOMMENDED — Supabase CLI (same end result as pasting SQL by hand)

  1. Install the Supabase CLI: https://supabase.com/docs/guides/cli
  2. Log in: supabase login
  3. From this repo’s web folder, link your hosted project (once):
       cd web
       supabase link --project-ref YOUR_PROJECT_REF
     (Project ref is in the Supabase Dashboard → Project Settings → General → Reference ID.)
  4. Apply every migration file under web/supabase/migrations/:
       supabase db push

  That applies migrations in order and matches what the app expects. Reload the app afterward.
